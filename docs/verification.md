修复验证需要覆盖真实大回包、完整轮次和任务归属不变，以及同一原会话的轻量执行；仅查看 `codex_health` 不能作为验收依据。原有失败任务和图片不得删除或自动重投。

当前修复的 `npm test` **122/122 通过**，发布隐私/文档检查和 `git diff --check` 通过。新增真实 STDIO 子进程集成用例覆盖 34–51 MiB 图片历史、连续同线程任务、外部运行任务阻挡、精确轮次图片恢复/幂等收集，以及启动结果未知时不重发。解析器还覆盖跨字节分片、UTF-8、字段顺序、非法 JSON、业务同形对象、路径段伪装、原型字段与资源限制。协议失败后的进程回收、强制退出兜底和关闭期间不复活有回归验证。

使用修复后的客户端只读读取同一真实会话，返回保留 9 个轮次、11 个图片项与 11 个 `savedPath`，不含内联图片结果，序列化后为 154,701 字节，无协议错误。没有清空或改写 Codex 后端上下文。

## 图片保底修复阶段（2026-10-14）

本次工作树新增图片项持久记录、完成原图保底副本和 `codex_collect_images`，并更新 Skill 的图片任务期限、文件处理及验收规则。2026-10-14 运行 `npm test`，83 项测试全部通过；这是当前本地修复的自动化结果，与下文首次 40 项测试及真实文件任务的历史验证分开记录。

本次覆盖的重点包括：

- 图片事件、终态与恢复核对保留原图；活跃精确 Turn 中已完成但漏掉通知的图片也可补收集。
- 失败/取消任务收集图片后，执行、验收和容量状态保持不变；不调用 `turn/start` 或 `thread/resume` 重新生成。
- `thread/read`、`thread/resume` 的延迟成功/错误响应不能覆盖其间新增的图片，或把已取消任务重新改为占用容量。
- 旧恢复响应和旧 `finish` 快照不能终结新一轮返工；旧图片事件不能错归后续任务。
- 图片保底副本不能满足空的最终产物报告；取消确认不会因图片复制失败而无法释放容量。
- 每任务 100 个图片记录的上限产生可见警告；文件类型、大小、路径、符号链接、重复复制及冲突文件有相应检查。
- 原缓存清理后仍重新校验既有工作区副本，避免再次收集时丢失已经交付的路径记录。

独立内存复现也确认：恢复请求等待期间收到图片与中断终态通知，旧回复返回后仍保留图片、`cancelled` 和已释放的容量。自动化图像检查使用测试样本，不代表已对真实生成内容、画质或用户要求的最终交付进行人工验收。

## 服务重启与返工

第一次真实任务创建一个指定两行内容的文件。独立检查精确内容后记录接受。随后重启网关服务，并对同一个任务发起返工，只修改指定的一行。

返工完成后再次独立核验文件内容与 Thread 一致性，任务保留原 ID、工作区和历史，执行轮次增加，结果再次被接受。

重启发生在已完成任务和后续返工之间。这证明任务/会话绑定能跨服务重启使用，不能扩大解释为所有运行中断都能无损自动续跑。

## 豆包工作端到端

通过正常应用界面观察到以下链路：

1. 豆包读取 `Doubao Codex Executor` Skill。
2. 发现连接器工具，调用 `codex_health` 和 `codex_workspaces`。
3. 调用 `codex_submit`，保存任务 ID，再调用 `codex_wait`。
4. Codex 在测试工作区创建要求的文件。
5. 豆包独立读取文件，检查字节数、行数及内容，随后调用 `codex_accept`。
6. 豆包对话显示最终结果；网关持久状态也为 `completed + accepted`。

测试文件内容为 `Doubao delegated this task to Codex.` 加一个末尾换行，共 37 字节。另用 Node `assert.equal` 独立比较了完整文件内容。验证依据是实际工具调用、文件和持久状态，不仅是模型的文字陈述。

## 过程中暴露的问题

- 新建 Codex Thread 在第一轮之前可能没有 rollout，立即 `thread/resume` 会失败。实现已区分当前进程中的新空会话与可恢复的已有会话。
- 模型目录或全局默认名称不代表当前认证方式支持推理。真实调用曾被模型权限拒绝，随后在网关专属配置选择实际可用模型完成验证；没有自动 fallback 或更改全局 Codex 默认配置。
- 直接以 Desktop 下的源码目录启动后台服务时出现过启动配置错误，因此正式安装复制运行代码到 Application Support。

这些失败保留在开发任务历史中，没有通过删除记录掩盖。具体私人标识和产物不随公开文档发布。

## 未覆盖范围

未验证或承诺其他操作系统、Codex 桌面侧栏自动同步、关机持续执行、已结束豆包对话的自动唤醒/主动通知、网页自动托管、文件自动上传或多租户隔离。
